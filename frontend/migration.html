    - Before you can select a 'dante taxCode' you have to select a 'Taxonomy'.
    - Before you can 'Create' a result OR add 'former taxCode' to JSON, you must create the corresponding fraction analysed for the corresponding sample in the ‘Fraction Analyzed’ accordion. if the fraction analysed is not in the ‘Fraction Analysed’ accordion, this must be set in the ArboDat2018 software.
    - If the ‘cf’ (classificationConfer), ‘restType’ and ‘stateOfPreservation’ attributes should be set with new existing Dante labels, these must be selected BEFORE add ‘former taxCode’ to JSON in the dropdowns. If ‘Add to JSON’ is to be chosen for the attributes, this can be done AFTER add ‘former taxCode’ to JSON.
    - You can set options from the dropdowns for all selected rows, by using the checkboxes on the left of each row. You can select or deselect all rows with the checkbox at the top left of a table.

    JSON

    If you add custom attributes which are not in the central thesauri lists (dropdowns), they will be saved here in JSON format. You can download this file and send it to us for review, so that new items can be added to the official lists in the future.
